═══════════════════════════════════════════════════════════════════
                 ⚠️ IF EMAIL NOT WORKING
═══════════════════════════════════════════════════════════════════

1. Email Password Missing?
   → Go to: https://myaccount.google.com/apppasswords
   → Generate new 16-character password
   → Add to .env: EMAIL_PASSWORD=abcdefghijklmnop
   → Restart server

2. "Invalid login" Error?
   → Password is wrong or expired
   → Follow step 1 above

3. Email in Spam?
   → Open email → Click "Report not spam"
   → Gmail remembers this

4. Timeout/Connection Error?
   → Check internet connection
   → Check firewall isn't blocking port 587

5. Terminal Shows "Email=false"?
   → .env not updated correctly
   → Server not restarted
   → Check steps above
