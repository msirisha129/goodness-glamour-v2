# Goodness Glamour 💄

A full-stack web application for beauty services and booking.

## Features
- User authentication (Google login)
- Booking system
- WhatsApp integration
- Admin panel
- Secure backend APIs

## Tech Stack
- Frontend: React / Vite
- Backend: Node.js / Express
- Database: MongoDB

## Setup
1. Clone the repo
2. Run `npm install`
3. Add `.env` file
4. Run `npm start`
